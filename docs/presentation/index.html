Source Code to ISO & VirtualBox Disk Pipeline

Compilation & Packaging Pipeline
PE32+ -> FAT32 -> GPT -> VDI / ISO

1. Rust Compilation

Compiled with the UEFI target triple: 

rustup target add x86_64-unknown-uefi
cargo build --release

Generates a PE32+ (Portable Executable 64-bit) binary with Subsystem 10 (EFI Application).

2. ESP FAT32 Staging

UEFI firmware requires standard FAT32: 

usb/
├── EFI/BOOT/BOOTX64.EFI
├── SHA256.txt
├── aeon-secureboot.cer
└── aeon.cfg

The UEFI specification dictates auto-booting from \EFI\BOOT\BOOTX64.EFI.

3. Disk Image Synthesis

Synthesized by build_disks.py: 

LBA 0: Protective MBR (0xEE)
LBA 1: Primary GPT Header
LBA 2-33: Partition Array
LBA 2048: FAT32 Partition Data

Converts raw GPT image to VirtualBox VDI with fixed UUID 3505efa3....

How UEFI Optical ISO (El Torito) Differs from VDI / Hard Disks

On an ISO 9660 optical disc image, BIOS used Sector 0 MBR boot code. UEFI systems do not read MBR bootcode; instead, Sector 17 contains an El Torito Boot Record pointing to a Boot Catalog. The catalog has a dedicated record with Boot Indicator ID 0xEF (UEFI Platform ID). This catalog entry points directly to an embedded FAT32 image containing \EFI\BOOT\BOOTX64.EFI. When VirtualBox or real PC firmware mounts the ISO, the UEFI Boot Manager extracts and boots the embedded EFI partition directly.

Universal Network Device Drivers: Intel e1000 & VirtIO

Hardware Driver Implementation
src/netdev.rs | src/e1000.rs | src/virtionet.rs

Intel 82540EM / 82545EM / 82574L Driver

Standard network interface for VirtualBox, VMware, and physical Intel NICs:

BAR

MMIO Register Mapping

Reads PCI BAR 0 (Memory Mapped I/O) and enables Bus Mastering in PCI Command register.

DMA

Circular Descriptor Rings

Allocates physical DMA frames for a 32-descriptor RX ring (RDBA) and 16-descriptor TX ring (TDBA).

MAC

Hardware MAC Retrieval

Reads physical hardware MAC address from EEPROM (EERD) or Receive Address Registers (RAL/RAH).

VirtIO-Net Paravirtualized Driver

High-performance network virtualization for QEMU / KVM and modern hypervisors:

VQ

Split Virtqueues

Initializes RX and TX virtqueues containing Descriptors, Available Ring, and Used Ring.

HDR

VirtIO Net Header Wrapping

Prepends 10-byte virtio_net_hdr structure to every outgoing Ethernet packet.

POLL

Non-Blocking Polling Engine

Monitors Used Ring indices to achieve high-throughput packet demultiplexing without interrupt overhead.

NetDev Unified Abstraction Layer (src/netdev.rs)

The kernel interacts with hardware exclusively through the NetDev trait, exposing name(), mac_address(), link_up(), send(&[u8]), and receive(&mut [u8]). Active devices dynamically fall back to Loopback if no physical PCI adapter is present.

Interactive Viva Defense Simulator

Q1: Why is this not simply a Linux distro? +
Aeon does not contain the Linux kernel. It is a 462 KiB bare-metal microkernel written in 100% pure Rust. It implements a Linux ABI translation layer over MSR_LSTAR fast syscalls, allowing it to execute Linux binaries while running on our own custom scheduler, memory manager, and page tables.
Q2: How does the network stack handle packet loss? +
The TCP engine implements an RFC 793 retransmission timer with sequence number acknowledgment. If an ACK is not received within the timeout window, the segment is retransmitted. ICMP ping tracks packet loss percentages by comparing transmitted sequence IDs against received echo reply tokens.
Q3: Why use UEFI instead of legacy BIOS? +
Legacy BIOS executes in 16-bit real mode with severe 1 MiB memory limitations and requires complex multi-stage bootloaders (boot sector -> stage 2). UEFI hands off execution directly in 64-bit long mode with a pre-configured linear GOP framebuffer, hardware TPM 2.0 protocol access, and modern GPT partition support.
Q4: How do you prove preemption works? +
The kernel includes two test workers (spawn). Worker tasks that loop infinitely without voluntary yields are preempted every 10 ms by the 100 Hz Local APIC timer interrupt. The scheduler flight recorder trace (trace) logs every preemption with reason code Timer.
