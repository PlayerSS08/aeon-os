## 8. Gotchas

- **Memory**: heavy QEMU runs were killed once when Windows free memory fell to about 1.3 GB. Check `powershell Get-CimInstance Win32_OperatingSystem` (free MB) first and aim for 3 GB or more. If a run is killed, do not restart it without the owner's word.
- Git Bash rewrites `/mnt/...` paths: use `MSYS_NO_PATHCONV=1` for WSL paths. Heredocs mangle backslashes: use the Edit/Write tools or script files.
- Python is not on the Windows path; run Python through WSL (`python3`, 3.14). From WSL, Windows paths do not work; use `/mnt/c/...` or `/mnt/g/...`.
- QEMU cannot type `>` or `!`; the tests use other characters. Key presses in the test VM are sequential, so use `vm.chord("ctrl", x)` for Ctrl+S.
- `usb/` was once rewritten by a signing run that I did not start (16:46). That was resolved by the 20:53 release run.
- The `/security-review` skill refuses when the working directory is not a git repo (`G:\Aeon` is not; `G:\Aeon\OS` is). Start the session in `G:\Aeon\OS`.
- Rules: plan before multi-file code; check Context7 for library APIs; run tests before saying done and say plainly if nothing ran; never put secrets in code; send mechanical edits to the `quick-edit` subagent; keep replies plain, short, with tables.
